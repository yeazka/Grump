# Grump

Grump is a Windows desktop island with expressive eyes, music controls, a timer, notes, to-do lists, and optional weather and activity indicators.

- [Website and interactive demo](https://yeazka.github.io/Grump/)
- [Download the Windows installer](https://github.com/yeazka/Grump/releases/latest)

This public repository hosts the website and installer releases. Desktop application development continues in a private repository. The interactive web demo is delivered as browser code and can be inspected by visitors.
