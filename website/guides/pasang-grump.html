Cara memasang Grump di Windows

Pilih Microsoft Store jika ingin instalasi dan pembaruan melalui Store. Kalau lebih suka file installer, unduh Grump 1.2.3 dari rilis GitHub resmi.

1. Pilih sumber unduhan

Buka Grump di Microsoft Store atau lihat rilis 1.2.3 di GitHub. Tautan GitHub menyediakan file Grump-Setup-1.2.3.exe. Unduh hanya dari halaman resmi tersebut atau melalui tombol di situs Grump.

2. Jalankan dan buka Grump

Untuk installer GitHub, buka file yang sudah diunduh lalu ikuti petunjuk pemasangan Windows. Untuk Microsoft Store, tekan tombol instal di halaman Store. Setelah selesai, jalankan Grump dari Start. Instalasi baru menampilkan pengenalan singkat untuk memilih tampilan awal.

3. Sesuaikan tampilan dan izin

Buka Preferences dari Grump untuk mengatur notch, Dock, musik, dan notifikasi. Fitur yang membaca notifikasi atau mengontrol bagian sistem memerlukan izin yang sesuai di Windows. Kamu bisa mengubah pilihan ini nanti; mulai saja dari fitur yang ingin dipakai.

Jika Windows menampilkan peringatan

Installer GitHub saat ini belum memiliki tanda tangan kode. Windows dapat menampilkan peringatan ketika file dijalankan. Pastikan nama file dan alamat unduhan cocok dengan rilis resmi sebelum memutuskan untuk melanjutkan. Bila ingin jalur instalasi melalui Microsoft, pilih halaman Store di atas.

Setelah terpasang

Putar lagu untuk mencoba kontrol musik, arahkan kursor ke notch untuk membuka panel, atau kenali cara memakai Dock. Kalau kamu belum melihat notifikasi, periksa izin notifikasi pada Windows dan pengaturan Grump.
