Mulai pakai Grump

Unduh Grump untuk Windows 10 atau 11 melalui installer resmi atau Microsoft Store. Mulai dari sini jika kamu baru mencoba Grump.

1. Pilih cara instal

Unduh installer 1.2.3 dari rilis resmi GitHub atau buka halaman Grump di Microsoft Store dari situs utama.

2. Jalankan aplikasi

Ikuti petunjuk pemasangan, lalu buka Grump. Pada instalasi baru, layar pengenalan akan membantu memilih tampilan awal.

3. Atur sesuai kebutuhan

Buka Preferences untuk mengatur notch, Dock, musik, notifikasi, dan tampilan. Kamu bisa mengubahnya lagi kapan saja.
